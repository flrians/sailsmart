Stand: 2026-06-25 (Pitch Deck Vorbereitung, zwei Decks)

**Markt-Kontext:**
- Bavaria C50: Basispreis €379k, seit 2017 produziert, 4 Kabinen-Layouts
- Bavaria gesamt: 42.000+ Boote seit 1978, einer der Top-3 globalen Yacht-Hersteller (30-56 Fuß)
- C-Line Modelle: C38, C42, C45, C46, C50, C57, C65
- Segelboot-Markt global: $13.85B (2024), CAGR 10.8% bis 2032

**Stärkste Product Moats:**
1. Proprietäre Bavaria-Dokumente als Embedding-Corpus (nicht frei verfügbar)
2. boat_type-spezifisches RAG (Kontext-Filterung per User-Profil)
3. Chat-History + Nutzungsverhalten als späterer Feedback-Loop
4. Erster Mover in strukturiertem Bavaria-Ökosystem

**Roadmap-Horizonte:**
- Q3 2026: Foundation (Onboarding, Suggested Questions, Chat-Feedback, Mobile-UX)
- Q4 2026: Monetarisierung (Freemium/Paywall, Bavaria C45/C57 Expansion)
- Q1-Q2 2027: B2B Charter-Produkt (QR-Code Access, Operator-Dashboard, Multi-Language) — VORGEZOGEN: Feature-Spec geschrieben 2026-06-29, Florian plant Umsetzung früher als geplant. Riskanteste Annahme unvalidiert: ob Chartergesellschaften QR aktiv einsetzen. Empfehlung: erst manuell einen Token für einen Operator anlegen, bevor Self-Serve-Dashboard gebaut wird.
- 2028+: Multi-Hersteller-Vision (Jeanneau, Beneteau, Hanse)

**Why:** Pitch Deck Vorbereitung erfordert klare Narrative für Investoren — Fokus auf Moat, Expansion-Credibility und Charter als B2B-Umsatzkanal.
