Stand: 2026-06-25

**Direkte Wettbewerber (AI Yacht Assistant):**

1. **Next Yacht Group — Next AI-Integrated System** (Oct 2025, Fort Lauderdale)
   - Lokal-first, on-board installiert (kein Cloud-Fokus)
   - Zielgruppe: Luxury Superyachts (AB Yachts, Maiora)
   - Steuert Yacht-Funktionen (Licht, Klima, Entertainment)
   - Kein Web-App-Ansatz, kein SaaS-Modell

2. **YachtWyse** (2026, Web App)
   - AI-powered Diagnostic Assistant via Chat
   - Engine diagnostics, maintenance suggestions
   - Nicht manual-spezifisch, generischer Ansatz

3. **OwlMar** (2026)
   - Ähnlich wie YachtWyse, Yacht Management App
   - Keine manual-spezifische RAG-Implementation bekannt

4. **Saxdor AI / MySaxdor App** (2024/2025)
   - Herstellereigene App (Saxdor Powerboats)
   - AI Copilot für Navigation und Steuerung
   - Vertikales Produkt eines Herstellers, kein SaaS

**SailSmart Differenzierung:**
- Einziger Ansatz mit modell-spezifischem RAG auf proprietären Hersteller-Manualen
- Web-App (no app store dependency, Tablet im Cockpit)
- Multi-Model-Architektur (Bavaria-Ökosystem, dann Hersteller-agnostisch)
- B2C + B2B (Charter) in einem Produkt

**Wichtige Erkenntnis:** Luxury-Segment ist besetzt (Next Yacht Group), aber Volumen-Segment (Bavaria, Jeanneau, Beneteau — 40-65 Fuß Produktionsboote) ist unbesetzt. Das ist SailSmarts Zielmarkt.
