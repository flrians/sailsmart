## Monatliche Fixkosten (ab ~100–500 MAU)

| Position | Kosten/Monat | Notiz |
|---|---|---|
| Supabase Free | €0 | bis ~500 MAU |
| Supabase Pro | $25 + Usage | ab ~500 MAU, inkl. 50k Auth MAU |
| Vercel Hobby | €0 | bis Produktions-Scale |
| Vercel Pro | $20/Monat | ab Skalierung / Team |
| Domain + Tools | €50–100 | Fix |

## Frühphase (0–200 zahlende User)
- Supabase: €0 (Free Tier)
- Vercel: €0 (Hobby)
- Domain/Tools: €50–75/Monat
- **Gesamt Infrastruktur: ~€50–75/Monat**

## Wachstumsphase (200–1000 zahlende User)
- Supabase Pro: ~$50–75/Monat (inkl. Usage)
- Vercel Pro: $20/Monat
- Domain/Tools: €75/Monat
- **Gesamt Infrastruktur: ~€150–200/Monat**

**Why:** Supabase und Vercel haben großzügige Free-Tiers, die in der Frühphase keine Fixkosten verursachen. Erst ab ~500 MAU fallen signifikante Infra-Kosten an.

**How to apply:** Break-Even-Szenarien können mit minimaler Infra-Kostenbasis (€50–75/Monat) gerechnet werden, die erst bei Skalierung steigt.
