## Marktgröße

**Bavaria C50 Flotte (geschätzt):**
- C50 in Produktion seit 2018, Bavaria produziert ~1.500–2.000 Yachten/Jahr total
- C50 ist ein Modell unter ~10 aktiven Modellen → ~150–200 C50/Jahr Produktion
- 6–7 Produktionsjahre (2018–2025) → ~900–1.400 C50 weltweit
- Konservative Basis: **~1.000 Bavaria C50 weltweit**

## Break-Even-Szenarien

**Fixkosten monatlich:**
- Infra (Phase 1): €75/Monat
- Tools/Domain: €50/Monat
- Gesamt ohne Gehalt: €125/Monat

**Szenario 1 — Kein Gehalt:**
- Break-Even bei ~13–15 zahlenden Usern (€125 / €10 ARPU)

**Szenario 2 — €3.000/Monat Gehalt:**
- Break-Even bei ~313–315 zahlenden Usern (€3.125 / €10 ARPU)

**Szenario 3 — €5.000/Monat Gehalt:**
- Break-Even bei ~513–515 zahlenden Usern (€5.125 / €10 ARPU)
